# Git + GitHub Master Course

Welcome to the Git and GitHub Master Course!

This repository provides structured learning material for students, beginners, and developers who want to learn version control, manage source code, collaborate with teams, and use GitHub professionally.

## About This Course

Git is a distributed version control system used to track changes in source code. GitHub is an online platform that hosts Git repositories and provides collaboration tools for software development.

This course takes you from the fundamentals of Git to advanced workflows used in real-world software development.

## Learning Objectives

By completing this course, you will be able to:

- Understand version control and its importance.
- Explain the difference between Git and GitHub.
- Install and configure Git on your computer.
- Use Git commands through the VS Code terminal.
- Create repositories and track file changes.
- Connect local repositories to GitHub.
- Push and pull code between local and remote repositories.
- Create branches and merge changes.
- Resolve merge conflicts.
- Collaborate through forks and pull requests.
- Manage GitHub projects professionally.
- Troubleshoot common Git errors.
- Contribute to open-source projects.

## Course Prerequisites

- Basic computer knowledge.
- Visual Studio Code installed.
- Git installed on your computer.
- A GitHub account.
- Basic understanding of files and folders.

No previous Git experience is required.

## How to Use This Repository

1. Start with Module 01.
2. Read the theory and command explanations.
3. Practice each command in a sample project.
4. Complete the exercises provided in each module.
5. Test your knowledge using the MCQ questions.
6. Prepare for technical interviews using the interview questions.
7. Complete the practical projects to strengthen your skills.

## Recommended Learning Approach

Learn one concept at a time. Execute the commands yourself instead of simply memorizing them.

Always check the current repository status before committing, merging, or pushing changes.
