
# Git + GitHub Learning Roadmap

A step-by-step roadmap to master Git and GitHub, from beginner fundamentals to professional development workflows.

## Phase 1: Git Fundamentals

- [ ] Understand version control.
- [ ] Learn what Git is.
- [ ] Learn what GitHub is.
- [ ] Understand Git vs GitHub.
- [ ] Learn repositories, commits, branches, and remotes.
- [ ] Understand the Git workflow.

**Goal:** Understand why developers use Git and GitHub.

## Phase 2: Installation and Configuration

- [ ] Install Git on Windows.
- [ ] Verify installation using `git --version`.
- [ ] Configure Git username.
- [ ] Configure Git email.
- [ ] Learn global and local configuration.
- [ ] Open the terminal in VS Code.
- [ ] Understand PowerShell and Git Bash.

**Goal:** Prepare your computer for version control.

## Phase 3: Basic Git Commands

- [ ] Learn `git init`.
- [ ] Learn `git status`.
- [ ] Learn `git add`.
- [ ] Learn `git commit`.
- [ ] Learn `git log`.
- [ ] Learn `git diff`.
- [ ] Understand the working directory.
- [ ] Understand the staging area.
- [ ] Practice making multiple commits.

**Goal:** Track project changes using Git.

## Phase 4: GitHub and Remote Repositories

- [ ] Create a GitHub account.
- [ ] Create a repository on GitHub.
- [ ] Understand local and remote repositories.
- [ ] Learn `git remote`.
- [ ] Connect a local repository to GitHub.
- [ ] Learn `git push`.
- [ ] Learn `git pull`.
- [ ] Learn `git fetch`.
- [ ] Learn `git clone`.
- [ ] Upload a project from VS Code.

**Goal:** Publish your local projects on GitHub.

## Phase 5: Branching and Merging

- [ ] Understand why branches are useful.
- [ ] Learn `git branch`.
- [ ] Learn `git switch`.
- [ ] Learn `git checkout`.
- [ ] Create a feature branch.
- [ ] Learn `git merge`.
- [ ] Understand fast-forward merges.
- [ ] Understand merge commits.
- [ ] Create and resolve a merge conflict.

**Goal:** Develop features independently and combine changes safely.

## Phase 6: Collaboration

- [ ] Understand collaborative development.
- [ ] Clone another developer's repository.
- [ ] Understand forks.
- [ ] Create a feature branch.
- [ ] Commit and push changes.
- [ ] Create a pull request.
- [ ] Review code.
- [ ] Respond to review comments.
- [ ] Understand issues and discussions.
- [ ] Contribute to an open-source project.

**Goal:** Collaborate with developers using GitHub.

## Phase 7: Advanced Git

- [ ] Learn `git stash`.
- [ ] Learn `git restore`.
- [ ] Learn `git revert`.
- [ ] Understand `git reset`.
- [ ] Learn `git cherry-pick`.
- [ ] Understand `git rebase`.
- [ ] Learn `git tag`.
- [ ] Understand detached HEAD.
- [ ] Explore `git reflog`.
- [ ] Learn safe recovery techniques.

**Goal:** Manage complex histories and recover from mistakes.

## Phase 8: Professional GitHub Features

- [ ] Write a professional README.
- [ ] Learn Markdown formatting.
- [ ] Create a `.gitignore` file.
- [ ] Protect sensitive information.
- [ ] Use GitHub Issues.
- [ ] Use GitHub Projects.
- [ ] Create releases and tags.
- [ ] Understand repository permissions.
- [ ] Build a GitHub profile README.
- [ ] Maintain meaningful commit messages.

**Goal:** Maintain professional and secure repositories.

## Phase 9: Troubleshooting

- [ ] Fix rejected pushes.
- [ ] Resolve merge conflicts.
- [ ] Fix authentication errors.
- [ ] Resolve unrelated history errors.
- [ ] Fix wrong-branch mistakes.
- [ ] Understand non-fast-forward errors.
- [ ] Recover lost commits when possible.
- [ ] Handle large-file problems.
- [ ] Diagnose common Git errors.

**Goal:** Solve common problems independently.

## Phase 10: Practical Projects

- [ ] Create a personal portfolio repository.
- [ ] Publish a web development project.
- [ ] Collaborate on a team project.
- [ ] Practice a feature-branch workflow.
- [ ] Complete a simulated code review.
- [ ] Contribute to an open-source project.
- [ ] Document projects professionally.

**Goal:** Apply Git and GitHub to real-world development.

## Phase 11: Knowledge Assessment

- [ ] Complete Git fundamentals MCQs.
- [ ] Complete Git command MCQs.
- [ ] Complete branching and merging MCQs.
- [ ] Complete GitHub collaboration MCQs.
- [ ] Practice Git interview questions.
- [ ] Complete practical command-line challenges.

**Goal:** Test your knowledge and prepare for interviews.

## Completion Checklist

- [ ] I can create and manage a local repository.
- [ ] I can commit changes with meaningful messages.
- [ ] I can connect a local project to GitHub.
- [ ] I can push and pull changes.
- [ ] I can create and merge branches.
- [ ] I can resolve basic merge conflicts.
- [ ] I can collaborate through pull requests.
- [ ] I can recover from common Git mistakes.
- [ ] I can maintain a professional GitHub repository.

---

**Recommended order:** Complete each phase in sequence and practice the commands in a dedicated learning repository.
